# Astra one-shot

A self-contained, responsive recreation of OpenAI's GPT-6 Astra launch experience. It uses original HTML, CSS, and JavaScript, with public media embedded from the original publisher.

## Local preview

```sh
npm run dev
```

Then open `http://localhost:4173`.

## Hosting

The public build is served from GitHub Pages. The included `vercel.json` also keeps the project ready for a zero-configuration Vercel deployment.
